# Odtwarzanie pojedynczej dostawy w GitHub Actions

**Historia dostawy c29b166bc4a79d03c012293ed7f6c83cffb3e9c6.** Poniższy opis dotyczy udanego artefaktu run 40008774472. Bieżący plik workflow został następnie przygotowany jako ręczny build/preflight/FTPS, bez triggera push i bez upload-artifact; pozostaje wyłączony. Aktualny plan, Secrets i blokady: [FTPS_DEPLOYMENT.md](FTPS_DEPLOYMENT.md). Nie uruchomiono go w fazie przygotowania.

Workflow `.github/workflows/translator-private-package.yml` działa wyłącznie na `feature/voice-translator-mvp` w publicznym `dar4med/sokuji`. Push reaguje tylko na zmianę tego pliku. Nie używa głównego projektu Sokuji, sekretów, cache zależności ani cache modeli. Oficjalne akcje są przypięte do SHA odczytanych z ich repozytoriów. Checkout nie zachowuje poświadczeń. Odziedziczony Build and Release pozostaje wyłączony; dodatkowe guardy blokują wszystkie 13 odziedziczonych zadań w tym forku.

`prepare-models.py --locked` nie odświeża locka, kart modeli ani licencji. Pobiera wyłącznie dotychczasowe rewizje i porównuje długość oraz SHA-256 wszystkich 34 wyników z `models.lock.json`. EN→PL odtwarza dotychczasową konwersję tokenizera i kwantyzację z przypiętej rewizji pełnych grafów. Metadane wejść także dotyczą tej rewizji. Dokładne wersje narzędzi pochodnych zapisano w `scripts/model-constraints.txt`; niezgodność wynikowego SHA kończy build, nie zmienia locka. Karty licencyjne są zachowane w Git. Runtime/WASM/VAD pochodzą z `npm ci` i istniejącego lockfile.

Build obejmuje TypeScript, 20 testów Node, CSP w Chromium oraz istniejący pełny test Basic Auth dla `/translator-test/` i osobnego originu root: 36 rzeczywistych tłumaczeń i 6 przebiegów ASR z kontrolowanym strumieniem audio. Nie oznacza to fizycznego mikrofonu ani odsłuchu TTS. Raporty muszą dotyczyć czystego bieżącego SHA. Offline konfigurator ma osobny test generowania i niezależną weryfikację bcrypt przez libcrypt, bez zapisu poświadczeń do dostawy.

Istniejący `package-private.py` weryfikuje SHA całej ekstrakcji oraz identyczność bajtów payloadu z testem Basic Auth. Oczekiwana lista archiwum to historyczne 74 pliki; `WERYFIKACJA-DOSTAWY.json` pokazuje ewentualną różnicę nazw i zawiera aktualne raporty. Bieżące SHA archiwum, SOURCE i manifestu będą nowe. `Require all denied` i hash CSP pozostają obowiązkowe. Konfigurator akceptuje tylko znany oryginalny hash `.htaccess`.

Do uploadu trafia wyłącznie osobny katalog dostawy: jeden skompresowany deployment ZIP, sidecary, instrukcja PL i mały ZIP konfiguratora. Nigdy rozpakowane `dist/`, `payload/`, modele drugi raz, nagrania, źródła ani node_modules. `compression-level: 0` zapobiega ponownej kompresji dużego ZIP. Retencja **1 dzień**, bez nadpisywania. Dostawa powyżej 350 000 000 B kończy zadanie przed uploadem. Błąd quota kończy zadanie; brak zakupów i automatycznych obejść.

Koordynator potwierdził 2026-10-23 w panelu konta GitHub Free: Actions storage 0 GB / 0,5 GB, billable usage $0. API rozliczeń pozostaje niedostępne dla integracji. To potwierdzenie dotyczy **jednego** artefaktu ok. 331 MB, nie kolejnych kopii. Nie uruchamiaj ponownie po udanym uploadzie bez potwierdzenia wolnego współdzielonego limitu Actions + Packages lub wygaśnięcia poprzedniej pełnej dostawy. Nie zmieniaj budżetów ani planu. Artefakty i kod repozytorium publicznego nie służą przechowywaniu sekretów.

Pakiet ma przenośne `base: './'` i został sprawdzony dla `/translator-test/`. Jego przygotowanie nie publikuje niczego na hosting. Jedynym celem późniejszej ręcznej wysyłki jest `public_html/translator-test/` w zaakceptowanej przestrzeni `ai.lekarz.nl-ohp3/`, z oddzielnym preflight Basic Auth i rzeczywistej konfiguracji LiteSpeed. Instrukcja WinSCP rozdziela payload od dokumentacji/narzędzia i wymaga ochrony przed udostępnieniem plików. Pozostają otwarte próby fizyczne Android/iPhone, odsłuch lokalnego TTS i ludzka ocena semantyki; znane `stoi → ligt` nie jest technicznym sukcesem semantycznym.
